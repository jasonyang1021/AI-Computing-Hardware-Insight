# 1. Purpose

CHIF（Computing Hardware Insight Framework）是整个项目统一的分析方法论。

CHIF 不属于任何具体技术方向。

GPU、HBM、Chiplet、Glass Core、PCB、MLCC、EDA、半导体设备、AI Server 等所有领域均采用同一分析框架。

CHIF 的目标不是回答技术问题，而是帮助形成具有产业价值和战略价值的 Insight。

---

# 2. Design Philosophy

CHIF 建立在以下原则之上：

- Thinking Before Answering
- Industry Before Technology
- Insight Before Information
- Decision Before Description
- Evidence Before Conclusion

任何分析必须遵循统一思考路径，而不是按照知识点罗列。

---

# 3. Insight Pyramid

所有分析必须沿着以下路径逐层提升。

```text
Data
    │
    ▼
Information
    │
    ▼
Knowledge
    │
    ▼
Insight
    │
    ▼
Decision
````

解释：

## Data

原始数据。

例如：

工艺节点

良率

市场规模

价格

性能指标

---

## Information

经过整理后的信息。

例如：

某企业推出新产品。

某工艺进入量产。

---

## Knowledge

建立知识关系。

例如：

HBM 带宽推动 AI GPU 性能。

Glass Core 提高封装密度。

---

## Insight

回答：

为什么发生？

为什么重要？

未来意味着什么？

---

## Decision

形成建议。

例如：

投资建议

研发方向

供应链策略

国产替代机会

如果分析停留在 Data 或 Knowledge，则不能称为产业洞察。

---

# 4. CHIF Thinking Framework

所有分析必须依次回答九个问题。

---

## Step 1 — WHY

为什么存在？

为什么需要？

产业驱动力是什么？

商业价值是什么？

---

## Step 2 — WHAT

研究对象是什么？

核心技术是什么？

关键指标是什么？

目前发展状态如何？

---

## Step 3 — WHO

谁参与？

包括：

企业

高校

研究机构

标准组织

产业联盟

关键人才

开源社区

---

## Step 4 — HOW

如何实现？

包括：

技术路线

产品架构

制造流程

关键工艺

实现难点

---

## Step 5 — WITH WHAT

依赖哪些基础能力？

包括：

材料

设备

EDA

PCB

MLCC

封装

测试

软件生态

制造能力

---

## Step 6 — WHO SUPPLIES

供应链是谁？

必须识别：

全球供应商

区域分布

市场份额

供应风险

国产替代能力

---

## Step 7 — WHO COMPETES

竞争格局如何？

包括：

市场领导者

追赶者

新进入者

竞争优势

竞争壁垒

生态优势

---

## Step 8 — WHAT NEXT

未来如何演进？

必须包含：

技术路线图

市场趋势

供应链变化

产业重构

时间节点

---

## Step 9 — SO WHAT

最终形成决策。

必须回答：

应该关注什么？

风险是什么？

机会在哪里？

下一步应该采取什么行动？

---

# 5. CHIF Analysis Dimensions

每个分析必须覆盖以下九个维度。

| Dimension     | Key Question |
| ------------- | ------------ |
| Strategy      | 为什么值得研究？     |
| Market        | 市场需求是什么？     |
| Technology    | 技术路线是什么？     |
| Product       | 产品如何演进？      |
| Manufacturing | 如何制造？        |
| Supply Chain  | 谁提供？         |
| Competition   | 谁领先？         |
| Ecosystem     | 谁构建生态？       |
| Outlook       | 下一阶段是什么？     |

根据主题可以调整分析深度，但不得省略关键维度。

---

# 6. Evidence Rules

所有重要结论必须标注证据等级。

| Level | Source         |
| ----- | -------------- |
| A     | 官方数据 / 财报 / 标准 |
| B     | 行业报告           |
| C     | 学术论文           |
| D     | 专家观点           |
| E     | 合理推断           |

预测必须明确说明依据。

不得将推断描述为事实。

---

# 7. Output Rules

任何 Skill 输出均应符合统一结构：

1. Executive Summary
2. Key Findings
3. CHIF Analysis
4. Risk Assessment
5. Future Outlook
6. Recommendations

不同 Skill 不得自定义结构。

---

# 8. Insight Checklist

最终输出前必须检查：

* 是否解释了 WHY？
* 是否识别了 WHO？
* 是否分析了 HOW？
* 是否识别关键供应链？
* 是否识别竞争格局？
* 是否进行了未来预测？
* 是否提出行动建议？

若任一项缺失，则分析不完整。

---

# 9. Maturity Model

CHIF 定义五级分析成熟度。

| Level | Description                      |
| ----- | -------------------------------- |
| L1    | 信息整理（Information）                |
| L2    | 技术分析（Technology Analysis）        |
| L3    | 产业分析（Industry Insight）           |
| L4    | 战略分析（Strategic Insight）          |
| L5    | 决策支持（Executive Decision Support） |

本项目默认目标为 **L4**。

对于董事会汇报、战略规划、重大技术路线分析，应达到 **L5**。

---

# 10. Evolution

CHIF 是整个 AI Computing Hardware Insight OS 的统一分析框架。

未来允许：

* 新增分析维度
* 新增检查项
* 新增成熟度模型
* 新增行业适配

但以下原则保持不变：

* Thinking Before Answering
* Insight Before Information
* Decision Before Description
* Evidence Before Conclusion
