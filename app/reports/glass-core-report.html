产业链全景

核心问题：Glass Core 产业价值到底掌握在哪些环节、哪些区域？

Key Takeaway：2026 年产业处于“多家试验线/样品线 → 量产验证”的临界区。真正稀缺的不是玻璃原片，而是跨越材料、TGV、金属化、RDL、检测、可靠性和 AI/HPC 客户验证的系统能力。

JKT 第一梯队

生态型优势

日本掌握特种玻璃、化学材料、精密设备；韩国加速把玻璃芯材料与 FC-BGA 载板能力闭环；台湾拥有先进封装与高端客户验证场景。最新信号是三星电机与住友化学子公司在 2026 年 7 月签署玻璃芯合资协议。

US 第二梯队

路线定义型优势

Intel 用 AI/HPC 大封装需求定义技术目标；美国通过 CHIPS/NAPMP 直接资助 Absolics 玻璃芯生态，并依托 Onto、Applied 等设备/工艺控制能力建立本土先进封装体系。

CN 第三梯队

制造追赶型优势

显示玻璃、精密加工、激光、湿法、电镀和面板搬运具有可迁移基础；但半导体级大板良率、超细 RDL、可靠性数据库和 AI 客户量产认证仍是核心 Gap。

材料体系分析

核心问题：哪些材料是真正的瓶颈，玻璃芯是否会“替代”现有材料体系？

Key Takeaway：Glass Core 不是“用玻璃替掉 ABF”这么简单。近中期最可能的主流形态是 玻璃芯 + 有机 Build-up / RDL 的混合结构；因此真正机会来自界面、附着、CTE 匹配、低损耗和大板均匀性，而不是单一玻璃原片。

P5

全球竞争格局

核心问题：为什么首先在日韩台形成？美国如何定义方向？中国到底处于什么位置？

Key Takeaway：全球竞争不是“三个地区同时做同一件事”。日韩台负责把产业链做成，美国负责把需求和架构定义清楚，中国的机会在于把大规模制造、设备国产化和成本工程做出来。
第一梯队 JKT

为什么先形成？

日本：特种玻璃、光刻胶、CMP、ABF、精密设备；NEG 已公开 515×510 mm TGV 大板样品路线，DNP 2025 年底启用 pilot line 并计划 2026 年初送样，TOPPAN 计划 2026 年 7 月投运先进封装 pilot line。

韩国：FC-BGA 与大客户协同；Samsung Electro-Mechanics 公开目标 2027 年量产，并在 2026-07-02 与 Sumitomo Chemical 子公司签署 Glass Core JV 协议。

台湾：顶级先进封装与客户验证场景是核心价值，设备商也在 TGV/Panel 工艺布局。

第二梯队 US

如何定义路线？

Intel：公开给出玻璃相对有机基板可实现 50% 更低 pattern distortion、潜在 10× interconnect density，并把首批应用锁定数据中心、AI、图形等大尺寸高速封装。

政策：CHIPS NAPMP 2025 年宣布向 Absolics、Applied Materials、ASU 各 1 亿美元项目支持，其中 Absolics 项目明确用于构建 glass-core packaging ecosystem。

设备：Onto、Applied 等掌握 process control / lithography / metrology 关键能力。

P6

未来技术路线

核心问题：未来五年 Glass Core 会沿哪几条路线演进？

Key Takeaway：未来五年的主线不是“全玻璃替代一切”，而是从 Glass Core + Organic Build-up 起步，逐步走向大 Panel、细 RDL、光电共封装与系统级封装。Glass 的真正驱动力是 Package Size Expansion。

1. 五条路线

Route A · 最可能先量产

Glass Core + ABF Build-up

用玻璃解决刚性、平整度、尺寸稳定性；保留成熟有机 build-up 做细线与多层。
判断：近中期主航道。

Route B

Glass Interposer + Organic Substrate

Glass 先替代部分 silicon interposer / large-area interposer 功能。
判断：适合大尺寸与成本敏感场景。

Route C

Panel-Level Glass

510×515、600×600、650×650 mm 工具链逐步成熟。
判断：决定成本曲线，但也是良率最难点。

Route D

CPO / Optical Integration

利用玻璃电学、光学与尺寸稳定性，承接光引擎、无源器件、低损耗互连。
判断：高战略价值。

Route E · 远期

System-on-Glass / All-Glass

更大系统边界、更高集成度，但材料界面、组装、返修与可靠性风险高。
判断：先研发，不宜过早量产下注。

路线竞争

TGV 工艺双路线长期共存

Laser modification + etch 追求小孔/窄 pitch；CO₂ direct drill 追求步骤少和吞吐。NEG 已公开同时覆盖两条路线。

中国企业建议

核心问题：未来中国最值得突破哪些方向，如何避免低水平重复投资？

Key Takeaway：中国不应把 Glass Core 定义为“再建一条玻璃线”，而应定义为 先进封装制造平台争夺战。最优策略不是全链条平均用力，而是优先攻下 5 个可形成系统壁垒的战场。

1. 五大战场优先级

S

大板 AOI / 3D Metrology / Warpage

理由：所有路线都需要，且 HVM 必须 inline。
KPI：sub-μm defect capture、TGV 3D、600 mm map、低 false call。

S

TGV + Metallization 联合平台

理由：单独打孔没有壁垒，孔形成到无空洞铜填充才是产品。
KPI：AR、void ppm、throughput、crack、uniformity。

S

Hybrid Glass + ABF / RDL

理由：最接近首批量产结构。
KPI：adhesion、2–5 μm roadmap、warpage、TCT/HAST。

A+

Panel 级 PVD / Plating / Handling

理由：中国具备装备制造与自动化迁移优势。
KPI：600 mm uniformity、breakage ppm、OEE。

A+

Reliability Test Vehicle & Standard

理由：没有长期数据就进不了 AI/HPC 供应链。
KPI：失效库、跨批次 correlation、客户联合认证。

A

封装专用 Glass Composition

理由：长期关键，但不应脱离工艺单独开发。
KPI：CTE/TTV/strength/laser selectivity/chemical durability。
